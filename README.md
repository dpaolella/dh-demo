# Data Hub concept demo

> **This is not an official OpenGrid product.** It is an exploratory, illustrative demo of what a
> hub for grid planning data could look like.

The demo is at https://dpaolella.github.io/dh-demo/ and needs a password. This repository holds
only the encrypted page that site serves. If you were invited to look at the demo and don't have
the password, ask the person who sent you the link.
